# toolkit

Консольный набор утилит: Python-пакет с CLI, содержащий калькулятор и конвертер величин.

## Установка

Из папки `lab_01`:

    pip install -e .

## Использование

Калькулятор:

1. Поддерживает целые и вещественные числа
2. Поддерживает +, -, *, /
3. Поддерживает унарный знак перед числом
4. Игнорирует проблемы между токенами
5. Соблюдает приоритеты

При  использование калькулятора необходимо перейти в toolkit/src и написать:

    py -m toolkit calc "2+3*4"        # 14.0
    py -m toolkit calc "10 / 4"       # 2.5

Конвертор:

1. Поддерживает группы: 1. Длина: mm, cm, m, km
                        2. Масса: g, kg
                        3. Температура: c, f, k
2. Не учитывает регистр 
3. Конвертация между разными группами запрещена

При  использование конвертора необходимо перейти в toolkit/src и написать:

    py -m toolkit convert 1000 --from mm --to m     # 1.0
    py -m toolkit convert 100 --from c --to f       # 212.0



## Как устроен калькулятор

1. `tokenize` разбивает строку на числа и операторы, унарные `+` и `-`
   сразу становятся частью числа.
2. `validate` проверяет, что числа и операторы чередуются.
3. `evaluate` считает в два прохода: сначала `*` и `/`, потом `+` и `-`.

Вычислительное ядро (`calculator.py`, `converter.py`) ничего не печатает
и не читает ввод. Ввод, вывод и коды возврата — только в `__main__.py`.

## Ошибки и коды возврата

При ошибке сообщение выводится в stderr, код возврата 2. При успехе — 0.
Ошибки: пустое выражение, некорректное выражение (два оператора подряд, лишние скобки), деление на ноль, температура ниже абсолютного нуля, конвертация разных групп, конвертация неизвестных групп.
